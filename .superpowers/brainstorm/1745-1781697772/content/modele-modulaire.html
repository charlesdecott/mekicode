Le modèle modulaire — est-ce bien ça ?

Tout en NiceGUI. Deux familles de classes de base ; les nodes se composent de composants ; deux briques sont partagées entre le chat et le canvas (le composant Chat, et le bus de hooks).

① Composants réutilisables (BaseComponent NiceGUI)

BaseComponent ├─ HeaderComponent (titre, collapse, glyphe) ├─ ChatComponent ◄ partagé ├─ QueueComponent (file d'attente) ├─ EditorComponent (éditeur + preview) ├─ FileTreeComponent (explorateur) └─ GitComponent / TerminalComponent…

Un composant peut contenir d'autres composants ou des nodes.

② Nodes (BaseNode NiceGUI, posée sur le canvas)

BaseNode (position, parent, collapse) KernelNode └ GitNode ├ ChatNode → contient ChatComponent │ └ QueueNode → QueueComponent (sous le chat) ├ SubcanvasNode │ └ ExplorerNode → FileTreeComponent │ └ FolderNode │ └ EditorNode → EditorComponent └ TerminalNode / …

Une node dérive de BaseNode et se compose de composants. Le parent est dérivé (pas stocké) → câbles déduits.

PARTAGÉ — un seul ChatComponent : Onglet « Chat » ─┐ ├─► ChatComponent (même classe, même rendu) ChatNode (canvas) ─┘ PARTAGÉ — un seul bus de hooks (NOS hooks, pas ceux de Claude Code) : mekicore dispatch_tools ──(pre_tool / post_tool / on_event)──► HookBus ├─► Chat : tool-cards └─► Canvas : impulsions (comète + glow)
✓
